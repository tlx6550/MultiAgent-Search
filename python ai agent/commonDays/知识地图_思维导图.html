Python + AI Agent
学习作战地图

目标不是「学完 Python」，而是在 8 周内交付一个能部署、能演示、能写进简历的 Agent 服务。 这张地图按依赖关系排序：先能读代码，再能写工具，最后能上线。

01 / STRATEGY

先把目标定义对

Naval 思维：用具体知识 + 杠杆，而不是用「学习时长」感动自己。

目标重定义

60 小时不足以「熟练掌握 Python」的全部语法，但足够完成一次 最小可行跨越：能读、能改、能写工具、能部署一个真实 Agent 服务。 剩下的深度，在你上线之后靠真实需求补齐。

把目标从「学 Python」改成「上线一个 Agent 产品」。 前者没有终点，后者有验收标准：能被访问、能调用工具、能流式返回、能记录日志。

反向思考：明确不学

  • ×机器学习数学、反向传播、模型训练
  • ×从零手写 Agent 框架 / 啃 AutoGPT 源码
  • ×Python 全栈课程从第一章刷到最后一章
  • ×同时学 Django、Flask、FastAPI 三套后端

你不是要成为算法工程师，你要成为能把模型接到业务里的人。

06 / METHOD

四种学习武器，每天都要用

方法不是装饰，是决定 60 小时能换回多少能力。

01 / FEYNMAN

费曼：讲不清 = 没学会

每天用 3 句话讲今天的概念，不许用术语。卡住的地方就是漏洞，立刻回到代码里补。

今天讲：Agent 是一个「会自己决定调用什么工具」的程序。
02 / DELIBERATE

刻意练习：只练一个点

每次只攻克「刚好超出当前能力」的单项技能，并有即时反馈。今天的靶心是：字典遍历 + 函数。

验收脚本就是反馈器；红变绿才算完成。
03 / SCOTT YOUNG

高效学习：直接做真事

不先刷完课程。用「获取 → 理解 → 拓展 → 纠错 → 应用」直接复刻真实项目，用 Vue 经验做类比。

类比：WebSocket ≈ 你熟悉的实时通道；ContextVar ≈ 每个标签页独立 store。
04 / NAVAL

杠杆：让一份努力被复用

代码、笔记、复盘都是可复用资产。每天一次 commit，让学习产生复利；把成果公开，获得机会杠杆。

今天结束：commit 一次，并把笔记归档到云端。
05 / FEEDBACK

用错误驱动，而不是用教程驱动

每遇到一个报错，只记录三件事：报错原文、根因、下次如何避免。错误日志比笔记更值钱。

建一个 errors.md，今天至少记录 1 条。
06 / CADENCE

固定节奏：10 / 35 / 10 / 5

看 10 分钟、写 35 分钟、讲 10 分钟、记 5 分钟。时间盒能防止「看视频看到睡着」。

手机计时器从踏进学习状态那刻开始。
07 / PRODUCTION

中国国情下的落地清单

能用国内服务就别绕路；先合规，再上线。

技术选型

  • 大模型：DeepSeek、阿里云百炼（通义）、智谱 GLM、火山方舟（豆包）
  • 联网搜索：博查 AI 搜索、阿里云 IQS；Tavily 可作备用
  • 知识库：RAGFlow（可自托管）、Dify（低代码）
  • 数据库：MySQL / PostgreSQL，先用 Docker 起本地实例
  • 部署：阿里云 / 腾讯云轻量服务器 + Docker + Nginx
  • 前端：你的 Vue 项目通过 WebSocket 接流式进度

上线前检查

  • 密钥：.env 不进 git，服务器用环境变量或密钥管理
  • 鉴权：WebSocket 与任务接口必须带 token，不能裸奔
  • 限流：按 IP / 用户限制任务数，防止 token 被刷爆
  • 数据：敏感数据不出境；日志脱敏
  • 成本：设每日预算与最大 token，记录每次调用成本
  • 合规：公开运营需 ICP 与生成式 AI 相关备案；内部自用先做风险评估
最容易翻车的一点：把 API Key 写进前端或提交到 Git。上线前先搜一遍仓库。
